# Accenture FY26 PPTX Template — Slide Index

**Total slides:** 194
**Masters:** 3 slide masters — Dark (`#0A0011` bg), Light (`#FFFFFF` bg), and a variant Light.

## Color System

| Token | Hex | Name |
|---|---|---|
| bg (dark) | `#0A0011` | Near-black background (dark mode) |
| bg (light) | `#FFFFFF` | White background (light mode) |
| accent1 | `#460073` | Darkest purple |
| accent2 | `#7500C0` | Dark purple |
| accent3 | `#A100FF` | Core Accenture purple |
| accent4 | `#C2A3FF` | Light purple |
| accent5 | `#E6DCFF` | Lightest purple |
| accent6 | `#FF50A0` | Pink accent |
| text/dark | `#0A0011` | Body text on light slides |
| text/light | `#FFFFFF` | Body text on dark slides |

**Font:** Graphik Semibold (headlines), Graphik Medium (subheads), Graphik Regular (body).

**Slide modes:**
- **Light mode** = white `#FFFFFF` background, dark `#0A0011` text. Default for content slides.
- **Dark mode** = near-black `#0A0011` background, white `#FFFFFF` text. Used for emphasis, section openers, covers, dividers.
- **Purple mode** = `#7500C0` or `#460073` background. Used for vivid section dividers.
